# Larens Acotar Wiki

Um projeto educacional de uma wiki sobre o universo de **A Court of Thorns and Roses (ACOTAR)**, desenvolvido em HTML e CSS como trabalho de avaliação.

## Descrição

Este projeto apresenta um site informativo sobre a série de fantasía ACOTAR, incluindo informações sobre:
- **Personagens**: Feyre, Rhysand, Nesta, Cassian, Azriel, Morrigan, Tamlin, Lucien, Amren e Ianthe
- **Livros**: ACOTAR, ACOWAR, ACOMAF, ACOFAS e ACOSF
- **Locais**: Mapa e informações do universo
- **Pronuncias de personagens**: Áudio para aprender a pronunciar corretamente

## Recursos

### Imagens
- Fotografias de personagens principais
- Capas dos 5 livros da série
- Mapa do universo ACOTAR
- Logo e imagens temáticas

### Áudio
- Pronuncias corretas de 9 personagens principais
- Formato: MP3

### Estilos
- CSS personalizado para design temático
- Layout responsivo
- Tipografia com fontes do Google Fonts (Gotu, Shadows Into Light)
- Design temático com cores do universo ACOTAR

## Como Usar

1. Abra qualquer um dos ficheiros HTML (`Projeto 1a.html` até `Projeto 2f.html`) no seu navegador
2. Navegue entre as páginas usando os links disponíveis
3. Ouça as pronuncias dos personagens
4. Explore as informações sobre livros e personagens
